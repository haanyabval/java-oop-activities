# Group Task 5: Login and ATM System (Revised)

**Course:** Object-Oriented Programming Laboratory (ICS-01-302P), Group 5
**Professor:** Ms. Maria Cecilia Lojo
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## Task

Simulate a login system with a predefined username and password. The user has 3 attempts. Use string manipulation and flow control. Create an ATM system where a user can check balance, deposit money, and withdraw money (only if enough balance). Use a loop to keep showing the menu until the user chooses Exit.

## What it does

Login with 3 attempts (tells which credential is wrong), then an ATM menu loop for balance, deposit, and withdraw.
