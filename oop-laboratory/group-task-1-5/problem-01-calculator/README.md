**Course:** Object-Oriented Programming Laboratory (ICS-01-302P), Group 5
**Professor:** Ms. Maria Cecilia Lojo
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## Task

Create a Calculator class that can perform addition, subtraction, multiplication, and division of two numbers. Allow the user to choose the operation using a switch statement.

## What it does

Asks for two numbers, then loops on a `switch` so the user can try different operators on the same numbers, enter new numbers, or quit. Handles division by zero and invalid operators.
