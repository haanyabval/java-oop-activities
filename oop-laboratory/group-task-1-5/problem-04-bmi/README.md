# Group Task 4: Body Mass Index (BMI) Calculator (Revised)

**Course:** Object-Oriented Programming Laboratory (ICS-01-302P), Group 5
**Professor:** Ms. Maria Cecilia Lojo
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## Task

Write a program that computes a person's BMI. Use operators for calculation and flow control to classify: below 18.5 Underweight, 18.5-24.9 Normal, 25-29.9 Overweight, 30 and above Obese.

## What it does

Reads weight (kg) and height (cm) with input validation, computes BMI, prints the category, and gives a short health tip.
