# Group Task 2: Employee Net Salary Computation

**Course:** Object-Oriented Programming Laboratory (ICS-01-302P), Group 5
**Professor:** Ms. Maria Cecilia Lojo
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## Task

Write a program that computes an employee's net salary. The gross salary is input by the user. Deduct 10% for tax if the salary is above 20,000, otherwise 5%.

## What it does

Reads the gross salary, applies a 10% tax above 20,000 (otherwise 5%), and prints the tax and net salary.
