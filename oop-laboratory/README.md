# OOP Laboratory

Activities from the Object-Oriented Programming **Laboratory** course (ICS-01-302P) under Ms. Maria Cecilia Lojo.

## Group Task 1-5 (Group 5, revised versions)

| Problem | Summary |
|---------|---------|
| [Group Task 1: Calculator Program (Revised)](group-task-1-5/problem-01-calculator/) | Asks for two numbers, then loops on a `switch` so the user can try different operators on the same numbers, enter new numbers, or quit. |
| [Group Task 2: Employee Net Salary Computation](group-task-1-5/problem-02-net-salary/) | Reads the gross salary, applies a 10% tax above 20,000 (otherwise 5%), and prints the tax and net salary. |
| [Group Task 3: Circle Area and Circumference Calculator](group-task-1-5/problem-03-circle/) | Reads the radius and prints the area and circumference using `Math. |
| [Group Task 4: Body Mass Index (BMI) Calculator (Revised)](group-task-1-5/problem-04-bmi/) | Reads weight (kg) and height (cm) with input validation, computes BMI, prints the category, and gives a short health tip. |
| [Group Task 5: Login and ATM System (Revised)](group-task-1-5/problem-05-login-atm/) | Login with 3 attempts (tells which credential is wrong), then an ATM menu loop for balance, deposit, and withdraw. |
