# Practice Problem 2

**Topic:** Data types, swapping, type casting, Scanner input
**Instructor:** Mr. Ronel Paglomutan
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## Problems

| # | File | Task |
|---|------|------|
| 1 | [Main.java](src/Main.java) | Declare variables of all primitive data types and print them. |
| 2 | [SwapNumbers.java](src/SwapNumbers.java) | Write a program to swap two integers using a third variable. |
| 3 | [SwapNumbersNoTemp.java](src/SwapNumbersNoTemp.java) | Write a program to swap two integers without using a third variable. |
| 4 | [AreaofCircle.java](src/AreaofCircle.java) | Write a program that calculates the area of a circle (use double). |
| 5 | [TypeCastingDemo.java](src/TypeCastingDemo.java) | Write a program to demonstrate type casting (int to double, double to int). |
| 6 | [SimpleInterest.java](src/SimpleInterest.java) | Write a program to calculate simple interest. |
| 7 | [StudentDetails.java](src/StudentDetails.java) | Write a program that stores a student's details (name, age, grade) in variables and prints them. |
| 8 | [OddEven.java](src/OddEven.java) | Write a program to check whether a given number is even or odd. |
| 9 | [AverageThreeNumbers.java](src/AverageThreeNumbers.java) | Write a program to compute the average of three floating-point numbers. |
| 10 | [CubeVolume.java](src/CubeVolume.java) | Write a program to calculate the volume of a cube. |

## How to run

From this folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out Main
```

(Replace the class name to run a different problem.)
