# Laboratory Take Home: Hybrid Dialog App (JOptionPane)

**Source:** Laboratory Activity Take Home, p. 27
**Instructor:** Mr. Ronel Paglomutan
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## What it does

This program demonstrates a hybrid use of Java Swing dialogs by sequentially collecting user input, confirming actions, selecting arithmetic operations, performing calculations with error handling, and displaying results interactively through input, message, confirm, and option dialogs.

## How to run

From this folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out page27.HybridDialogApp
```
