**Source:** Laboratory Activity Take Home, p. 60

## What it does

The program demonstrates object-oriented programming by using encapsulation and arrays of objects to manage grocery items, calculate their total costs, and display a complete shopping summary efficiently.

From this folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out page60.ShoppingGrocery
```
