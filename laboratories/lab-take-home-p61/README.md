**Source:** Laboratory Activity Take Home, p. 61

## What it does

This Java program demonstrates Object-Oriented Programming by using a class with encapsulated attributes and a method to display shoe details based on user input.

## How to run

From this folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out page61.ShoppingShoes
```
