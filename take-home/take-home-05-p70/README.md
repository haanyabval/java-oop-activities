# Take Home 5: Login Frame (Swing GUI)

**Source:** Take Home, p. 70
**Instructor:** Mr. Ronel Paglomutan
**Documentation:** put the PDF in [`docs/`](docs/) and link it here.

## What it does

This program creates a simple Java Swing login window that allows the user to enter a username and password, validates the input, and provides options to clear the fields or exit the application.

## Files

| File | Class |
|------|-------|
| [LoginFrame.java](src/page70/LoginFrame.java) | `page70.LoginFrame` |

## How to run

From this folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out page70.LoginFrame
```
