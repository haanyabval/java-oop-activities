## What it does

The Java OOP Login System demonstrates encapsulation and user interaction by validating login credentials and allowing secure credential updates through object-oriented methods.

## How to run

From this folder:

```bash
javac -d out $(find src -name "*.java")
java -cp out loginpackageoop.LoginSystem
```
